# 화면번역 (ScreenTranslate)

영어 화면을 넘기면서 녹화하면 → 한국어 번역 PDF로 만들어 주는 윈도우 프로그램.

## 받기
[Releases → 화면번역 최신 버전](../../releases/latest) 에서 `ScreenTranslate.zip` 받아서 압축 풀고 `ScreenTranslate.exe` 실행.

## 쓰는 법
1. 번역할 영어 문서를 화면에 띄움
2. **F9** (녹화 시작) — 창이 내려가고 '삑삑' 소리
3. 한 장씩 넘김 — 넘긴 뒤 1초쯤 멈추면 그 화면이 저장됨('삑')
4. **F9** (녹화 끝) — 글자 인식 → 번역 → PDF가 자동으로 열림

결과 PDF 모양은 두 가지 중 선택:
- **원본 모양 그대로** (기본): 사진·배치는 원본 그대로, 영어 글자 자리에 한국어가 들어감. 사진 위에 얹힌 글자는 사진이 망가지지 않게 원본 유지
- **번역문만 정리**: 한국어 번역 + 영어 원문 작게

결과: `문서\화면번역\날짜_시간\` 안에 `번역_….pdf`, `번역_….txt`, `캡처\` (저장된 화면들)

OBS 등으로 녹화해 둔 영상이나 캡처 이미지도 **"녹화해 둔 영상 / 캡처 이미지로 만들기"** 버튼으로 넣으면 똑같이 PDF가 나옴.

## 구성
- 글자 인식: RapidOCR (PC에서 바로, 인터넷 불필요)
- 번역: 구글 번역(무료, 인터넷 필요)
- 같은 화면이 다시 나오면(앞으로 갔다 돌아옴) 자동으로 건너뜀, 메뉴·툴바·쪽번호는 자동으로 뺌
